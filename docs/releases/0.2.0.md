# Agentic Translating v0.2.0

[中文](#中文) | [English](#english)

## 中文

0.2.0 是一次面向本科毕业设计交付的能力与可靠性更新，重点完善工具调用、国际化、FSBP 证据链、本地凭据安全和 Windows 桌面体验。产品继续定位为本地单用户的高难中英双向翻译工作台，不包含 SaaS、多租户或公网运营功能。

### 主要更新

- **受限翻译工具**：聊天与编排链现在可以按阶段使用 `call_agents`、`write_draft`、`replace_text` 和 `submit_final`。参数 schema、权限、逻辑调用键、SQLite 轨迹、调用账本和事务化版本写入共同约束工具执行；批量替换失败时会回滚正文变更并保留失败证据。
- **完整中英文界面**：工作台、配置、历史、证据、对话、版本、弹窗和 Electron shell 接入同键 i18n catalog，语言偏好在重载和重开后保持。日期、数字、时长、费用与诊断信息按当前 locale 呈现。
- **可靠草稿恢复**：两个翻译方向分别保存工作台草稿。自动保存使用串行队列，预设异步加载、方向切换、提交和恢复之间增加竞态防护；读取或保存失败会明确显示并阻止覆盖已有草稿。
- **实时端点凭据**：每次实际模型请求都从当前端点记录原子读取地址、路径和 Key。历史会话不再发送冻结快照中的旧凭据；migration 17 清除活动会话快照中的结构化 Key 字段，公开 DTO、诊断和导出继续进行凭据脱敏。
- **流式与预检可靠性**：OpenAI 兼容 SSE 支持 reasoning 活动保活、无空行事件、完成原因和断流证据；空正文、仅 reasoning、截断和不完整终态会被拒绝或记录。付费调用前预检统一检查端点、上下文窗口和保留 token 预算。
- **诗歌保守门控**：诗歌团队加入目标语自然度视角，押韵根据任务要求和原作稳定形式按条件启用；最终编辑优先最小修改，并在忠实度或自然度退化时局部修复或回退。该修复发生在既有开发批次之后，质量效果仍需新的未见诗歌样本验证。
- **Windows 启动与发布边界**：Web 开发、Electron 开发和 standalone 预览使用相互隔离的 Next 缓存。发布树扫描拒绝数据库、私有实验材料、凭据、链接和缺失依赖；打包应用只启动随包携带的 standalone server。

## English

Version 0.2.0 is a capability and reliability update prepared for an undergraduate capstone delivery. It focuses on constrained translation tools, complete interface internationalization, FSBP evidence, local credential safety, and the Windows desktop experience. The product remains a local, single-user translation workbench rather than a SaaS or multi-tenant service.

### Highlights

- **Constrained translation tools:** chat and orchestration can expose `call_agents`, `write_draft`, `replace_text`, and `submit_final` by stage. Schemas, permissions, logical call keys, SQLite traces, the LLM ledger, and transactional version writes constrain state changes and preserve failed evidence.
- **Complete Chinese and English UI:** the workbench, configuration, history, evidence, chat, versions, modals, and Electron shell share parity-checked catalogs. Locale preferences survive reload and reopen, with localized diagnostics and formatting.
- **Durable direction drafts:** each translation direction keeps its own workspace draft. Serialized saves and async preset guards protect against navigation, reload, submission, and recovery races; load and save failures are visible and fail closed.
- **Live endpoint credentials:** every physical provider request atomically resolves the current endpoint address, path, and key. Historical session snapshots cannot resend stale credentials, while migration 17 removes structured key fields from active snapshot records.
- **Streaming and preflight reliability:** OpenAI-compatible SSE parsing handles reasoning activity, compact events, finish evidence, and interrupted streams. Empty-body, reasoning-only, truncated, and incomplete results are rejected or preserved with stable diagnostics; paid calls share a context-budget preflight.
- **Conservative poetry gate:** poetry teams include target-language naturalness, rhyme becomes conditional on the task and source form, and final editing favors minimal changes with fidelity/naturalness regression repair. This post-batch change still requires a new unseen poetry evaluation.
- **Windows startup and release boundary:** web development, Electron development, and standalone preview use separate Next caches. The release scanner rejects databases, private experiments, credentials, links, and missing dependencies; packaged builds start only their bundled standalone server.

### Validation

- TypeScript validation passed.
- Vitest: 1,180 passes and 2 skips in 119 files, with no failures.
- Locked FSBP dataset: 8 development and 16 test records passed validation; annotation-stress remains empty.
- Standalone: 26/26 static pages, 2,409 release files, and an isolated migration-18 startup smoke passed.
- Playwright: 17/17 focused bidirectional-draft and responsive-i18n workflows passed.
- The final packaged Windows application completed first launch, English switching and reload, a 390 px viewport, a 780 px viewport at 200% simulated zoom, direction switching, modal focus, and History. No missing-server failure, page error, console error, failed request, or model request was observed.

### Known boundaries

- Windows x64 installer and portable builds are provided without code signing.
- The twelve machine-readable `observed` fields in `i18n-fixture.jsonl` remain pending; product acceptance does not populate them automatically.
- The final packaged journey used a fresh profile without a key, so it created no session; post-submission export controls and complete direction-draft recovery were not exercised in that fresh-profile journey.
- The round-0820 quality evidence is a development batch with `formalEligible=false`, a dirty source state, and partial determinism. It is not a clean formal experiment.
- The conservative poetry gate is implemented but has not yet been evaluated on a new unseen poetry set.
